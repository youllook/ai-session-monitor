# AI 對話監看：導覽

用白話跟使用者解釋，一次只講他問到的部分，不要整份念出來。

## 面板每一列

```
● Claude [專案資料夾]: 對話標題                     ✕
  opus-5-5 · high                           執行中
對話 212.3K/1M (21%)
Cache: 21.2K | 58min | $0.45 | Total $3.10
```

- **燈號**：綠色閃＝執行中；黃＝閒置但快取還在；灰＝快取已過期或對話已結束。
- **對話 212.3K/1M (21%)**：這個對話目前多長／模型上限。每說一句，AI 都要把這整段重讀一次，所以越長每句越貴。顏色：未滿 50% 綠、未滿 75% 黃、未滿 90% 洋紅、90% 以上紅。
- **opus-5-5 · high**：目前的模型與思考強度。舊記錄讀不到其中一項時，面板就不顯示那一段。
- **Cache 第 1 格（21.2K）**：快取裡有多少。20 萬以上黃、50 萬以上紅。
- **Cache 第 2 格（58min）**：快取還能撐多久。過期（expired）後下一句要把整段重新寫進快取，比平常貴很多。
- **Cache 第 3 格（$0.45）**：最近一句話（含它觸發的所有動作）花了多少，照 API 牌價換算。超過 $0.10 黃、$0.50 紅。
- **Total**：這個對話從開始到現在的累計。
- **✕**：從清單移除；這個對話之後再有新動靜會自己回來。

金額是「如果照 API 計價會花多少」。用訂閱方案的人不是照這個扣錢，但它反映真實的用量。

## 為什麼會跳出 💸 提醒

對話裡出現 💸 開頭的提醒，表示越過了門檻：

- 對話超過 20 萬：提醒一次，建議換下一件事時 /clear。
- 對話超過 50 萬，或一句超過 $0.50：再提醒一次。
- 快取過期後又回來接著問：提醒這句要整段重建。

## 該怎麼做

- **/clear**：開新對話。換下一張單、下一件事就清掉，最省錢。
- **/compact**：壓縮對話。前面的內容還需要、但太長了時用，保留重點、其餘摘要。
- **/cost**：看這個對話花了多少。
- **/model**：換模型。對話中途換模型，快取會整段重建；要換就先 /clear。
  - Opus 5.5：預設，聰明穩定（$4／$20 每百萬 token）
  - Sonnet 5.5：快、便宜一半，日常工作通常夠用（$2／$10）
  - Haiku 5.5：最便宜，只適合很簡單的事（$0.1／$0.5）
  - Fable 5.1：最強也最貴，難題才用（$10／$50）
- **/effort**：思考強度 low → medium → high → xhigh → max。越高想得越仔細、難題比較不會錯，但比較慢也比較貴；簡單重複的事用 low／medium。結果不對先調高一級，不要一開始就開 max。

## 打開面板

面板關掉了想再打開：在終端機執行 `aimon panel`（Windows 的程式在 `%AppData%\ai-session-monitor\bin\aimon.exe`，mac 在 `~/Library/Application Support/ai-session-monitor/bin/aimon`）。開新的 Claude Code 對話時，面板沒在跑也會自己跳出來。
